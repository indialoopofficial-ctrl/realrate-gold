METHODOLOGY

How RealRate calculations work

Learn RealRate methodology: benchmark source, purity conversion, 3% GST estimate, selling deductions, old-gold formula and fallback rate handling.

1. Benchmark rates

RealRate uses the latest available IBJA benchmark as its primary reference. 24K is represented by the 999 benchmark, 22K by the 916 benchmark and 18K by the 750 benchmark when those values are available. Silver is shown using the 999 benchmark per kilogram.

2. Per-gram conversion

Gold benchmark values are commonly represented per 10 grams. The calculator divides the relevant 10-gram value by 10 to obtain an approximate per-gram benchmark. Silver per-kilogram values are divided by 1,000 for a per-gram estimate.

3. Purity conversion

For a karat without its own benchmark field, RealRate can estimate the metal value from 24K using the purity fraction. For example, 20K uses approximately 20/24 of the 24K benchmark. This is a mathematical purity estimate, not a replacement for physical testing.

4. BUY estimate and GST

The simple BUY estimate adds 3% GST to the benchmark metal value. Jewellery bills can include additional making charges, wastage and retailer premiums, so the final invoice can be higher than this basic estimate.

5. SELL and old-gold estimates

A selling estimate applies the deduction selected by the user to the benchmark value. Old-gold tools first convert tested purity into pure-gold equivalent, value that equivalent against the 24K benchmark and then apply the chosen buyer deduction. Real buyers may use different melting, refining or testing deductions.

6. Live, cached and saved status

When the live benchmark endpoint is available, RealRate marks the source as live. If it is temporarily unavailable, the site can fall back to a cached or saved benchmark so the calculator remains usable. Users should check the displayed update time before relying on a figure.

Important: RealRate is an informational calculator. Always verify the final buy or sell price, purity result, deductions and invoice with the jeweller or buyer before completing a transaction.
